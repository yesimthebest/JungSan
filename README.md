# 정산

결제 내역과 이미 이체한 돈 등을 반영하여 마지막 정산 과정에서 상호 간 송금 횟수를 최소화하게 돕는 서비스입니다. TypeScript + Supabase.

## 실행

```bash
npm install
npm run dev
```

## Live Demo

https://jungsan-ebon.vercel.app

## 기능

- 첫 화면에서 새 정산 시작 또는 참여 키 입력
- 여러 정산 오가기 가능
- 로그인 없는 참여 키 입력 방식
- 비용별 결제자, 금액, 분담 참여자 편집
- 이미 송금한 내역 입력 가능
- 최종 송금 경로 자동 계산
- 참여자 이름과 정산 이름 편집
- 브라우저 자동 저장
- JSON 백업 및 복원 가능
